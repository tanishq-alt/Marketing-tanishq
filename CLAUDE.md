# Claude Code Entry Point

Treat this repository as a modular marketing operating system.

Start with `SKILL.md`. For each task:

- identify the requested deliverable;
- identify the underlying marketing problem;
- load the relevant task skill under `skills/`;
- load only the knowledge modules referenced by that skill;
- state critical assumptions;
- generate or critique;
- run the relevant rubric before returning a final answer.

Never assume that a request for copy means the copy is the problem.
