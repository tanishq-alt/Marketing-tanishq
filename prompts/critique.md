# Critique Prompt

Audit the supplied marketing asset using the repository.

1. Define the intended audience and action.
2. Classify awareness and sophistication.
3. Score attention, relevance, clarity, differentiation, belief, value, friction, and CTA.
4. Identify the single biggest bottleneck.
5. Separate strategic problems from copy/design polish.
6. Flag unsupported or risky claims.
7. Recommend the smallest set of high-impact changes.
8. Preserve what already works.
