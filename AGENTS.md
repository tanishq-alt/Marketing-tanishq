# Agent Instructions

When using this repository as an AI agent:

1. Read `SKILL.md` first.
2. Route the task to one task-specific `skills/*/SKILL.md` file.
3. Load the smallest relevant set of `knowledge/` files.
4. Treat examples as illustrations, not templates to copy mechanically.
5. Distinguish facts supplied by the user from strategic assumptions.
6. Never fabricate proof, urgency, statistics, customer language, or competitor claims.
7. Diagnose before generating.
8. Prefer testable hypotheses over certainty when evidence is weak.
9. If market evidence conflicts with a framework, trust current market evidence.
10. Respect copyright: do not reconstruct or output large portions of source books.

For creative generation, produce genuinely different strategic territories before producing cosmetic variants.
