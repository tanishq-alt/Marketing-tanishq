# SKILL: Landing Page Optimizer

## Use when
- creating or auditing landing pages
- improving conversion
- aligning ads with pages

## Required inputs
- traffic source
- audience
- awareness
- offer
- proof
- current page/copy if auditing
- primary CTA

## Process
1. Identify visitor state on arrival.
2. Check message match.
3. Score orientation, relevance, value, difference, belief, risk, and action.
4. Identify the dominant failure.
5. Reorder sections based on awareness/sophistication.
6. Rewrite only after diagnosis.
7. Propose tests by leverage.

## Output standard
Audit score, primary diagnosis, recommended structure, rewritten key sections, and test plan.

## Failure modes
- universal page templates
- feature dumping
- proof far from claims
- multiple primary CTAs
- redesigning before message diagnosis

## Quality gate
Does each section earn the next section and reduce a specific uncertainty?
