# SKILL: Short-Form Video Strategist

## Use when
- Reels, Shorts, TikTok, feed video
- video hooks and structures
- retention diagnosis

## Required inputs
- audience
- payoff
- platform
- available visuals/proof
- desired CTA
- time limit

## Process
1. Define the promise of the first 1–3 seconds.
2. Choose visual + verbal hook together.
3. Deliver context only after earning attention.
4. Move proof/payoff earlier than feels comfortable.
5. Use pattern changes to maintain comprehension, not random stimulation.
6. Close with a CTA proportional to intent.
7. Create test variants for opening, payoff order, and CTA.

## Output standard
Hook, beat-by-beat structure, on-screen text, proof moment, CTA, and 3 test variants.

## Failure modes
- long intros
- bait-and-switch hooks
- visual clutter without information
- saving all value for the end
- judging success only by views

## Quality gate
Does the first frame set a clear promise, and does the video pay it off fast enough?
