# SKILL: Headline & Hook Writer

## Use when
- headlines
- subject lines
- video hooks
- ad openers
- first frames

## Required inputs
- audience
- channel
- actual payoff
- awareness
- sophistication
- available proof

## Process
1. Define the hook-body contract.
2. Generate strategic hook families.
3. Create variants inside each family.
4. Remove generic or over-claimed hooks.
5. Score relevance, usefulness, specificity, distinctiveness, believability, and fit.
6. Return a ranked set with what each tests.

## Output standard
Provide genuinely different hook families, not synonym variants. Include the hypothesis behind top options when useful.

## Failure modes
- clickbait
- generic curiosity
- hook disconnected from payoff
- optimizing attention from the wrong audience

## Quality gate
Would the hook attract the right person and set an expectation the content can actually satisfy?
