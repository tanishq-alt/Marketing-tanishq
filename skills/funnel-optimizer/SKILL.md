# SKILL: Funnel Optimizer

## Use when
- diagnosing conversion
- improving multi-step journeys
- reducing leakage

## Required inputs
- funnel steps
- traffic sources
- conversion data
- offer
- page/message assets
- known objections

## Process
1. Map each step and requested commitment.
2. Identify where qualified users drop.
3. Classify leak: traffic, promise, clarity, belief, offer, action, post-action.
4. Fix highest-upstream cause first.
5. Design a measurable test.
6. Check downstream quality to avoid local optimization.

- `knowledge/01-strategy/funnel-and-friction.md`
- `knowledge/02-copy/proof-and-believability.md`

## Output standard
Leak map, primary diagnosis, interventions ranked by leverage, and measurement plan.

## Failure modes
- optimizing CTR while harming conversion quality
- testing micro-copy before message match
- ignoring post-purchase experience

## Quality gate
Can you explain why users leave at each major step, not merely where?
