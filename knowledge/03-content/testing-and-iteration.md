# Testing and Iteration

Marketing testing should reduce uncertainty about causes, not merely create dashboards.

## Hypothesis format

> For **audience**, changing **variable** from A to B will improve **metric** because **reason**.

## Test hierarchy

Test high-leverage uncertainties before low-leverage details:

1. audience;
2. problem/desire;
3. promise;
4. positioning;
5. mechanism;
6. offer;
7. proof;
8. hook;
9. structure;
10. micro-copy / visual polish.

## Creative testing

A useful creative test changes one strategic variable clearly enough to learn from the result.

Bad test:
- 12 ads with different colors, headlines, visuals, and offers.

Better test:
- same audience and offer, three fundamentally different promise angles.

## Metrics

Match metrics to the stage:

- attention: thumb-stop / first-frame hold;
- engagement: meaningful watch/read depth;
- consideration: qualified click, product exploration;
- conversion: lead, trial, purchase;
- quality: activation, retention, refund, sales acceptance;
- brand: recall, preference, direct traffic, search lift where measurable.

A hook that lifts views but lowers qualified action may be a loser.
