# Virality and Sharing

Sharing is not a magical property of content. It is a behavior with motives.

## Why people share

Content is more shareable when it helps the sharer:

- express identity;
- help someone;
- signal taste/status;
- create affiliation;
- start conversation;
- make others laugh;
- explain a complex idea;
- warn others;
- participate in a cultural moment.

## Share test

Ask:

> What does sharing this content do for the person who shares it?

If the only answer is “it helps the brand,” the content has weak native spread.

## Design for spread

- make the useful unit easy to extract;
- give language people can repeat;
- create visible identity signals;
- reduce context required to understand;
- make the value arrive before the CTA;
- align format with where sharing actually happens.
