# Copy Principles

Copy is sales reasoning expressed in language.

## Primary jobs

Strong copy must:

1. earn attention;
2. communicate meaning;
3. build desire/preference;
4. build belief;
5. reduce relevant objections;
6. ask for action.

Not every asset must do all six, but every line should serve the job of the asset.

## Reader-first rules

- Use the audience's language where accurate.
- Prefer simple words to status-signaling vocabulary.
- Keep sentences short enough to process quickly.
- Break long passages into scannable units.
- Put important selling points in logical order.
- Start selling from the first relevant line; do not spend the opening warming up the writer.
- Use specificity when evidence allows it.
- Replace abstractions with observable outcomes.

## Feature → benefit → meaning

For each feature ask:

1. What does it do?
2. What changes for the user?
3. Why does that matter?
4. What emotion, risk, or identity is affected?

Example:

`automatic backup → files restore after failure → less downtime → peace of mind / professional reliability`

## Copy architecture

A robust general sequence:

`attention → relevance → problem/desire → promise → mechanism → proof → objections → offer → action`

Reorder based on awareness.

## Editing passes

1. Strategy pass — is the promise right?
2. Clarity pass — can it be understood once?
3. Specificity pass — can vague claims be made concrete?
4. Proof pass — what claims need support?
5. Compression pass — remove redundancy.
6. Rhythm pass — sentence variation and scanability.
7. CTA pass — is the next action obvious?
