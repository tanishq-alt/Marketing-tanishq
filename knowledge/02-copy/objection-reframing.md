# Objection Reframing

Not all objections should be “overcome.” Some reveal real product or fit problems. The marketer's job is to distinguish a misunderstanding from a legitimate trade-off.

## Three objection classes

1. **Comprehension objection** — “I don't understand it.”
2. **Belief objection** — “I don't believe it will work.”
3. **Trade-off objection** — “Even if it works, the cost/effort/risk is not worth it.”

## Reframing

Reframing changes the interpretation of a true fact without changing the fact.

Useful reframes:

- complexity → guided control;
- premium price → reduced total cost / higher service intensity;
- narrower scope → specialization;
- slower process → increased verification;
- required setup → one-time migration to reduce recurring work.

## Ethical boundary

Do not reframe a defect into a virtue when the promised virtue is false.

## Objection sequence

For each objection:

1. State it accurately.
2. Decide whether it is true.
3. If true, explain the trade-off and who should/shouldn't accept it.
4. If false, show mechanism or proof.
5. If partially true, narrow the claim.
