# Contributing

Contributions should make the system more useful, not merely larger.

## Good contributions

- a diagnostic that changes decisions;
- a clearer decision tree;
- a new cross-channel application of an existing principle;
- a scoring rubric with observable criteria;
- a worked example that demonstrates trade-offs;
- evidence that a principle fails under specific conditions.

## Avoid

- dumping book text into Markdown;
- formula lists without context;
- unsupported “best practices”;
- claims of universal effectiveness;
- examples that depend on fake numbers or invented social proof.

Each new knowledge file should include: definition, when to use, process, failure modes, and practical questions.
