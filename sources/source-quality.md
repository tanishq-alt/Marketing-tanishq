# Source Quality

## Tier A — direct full-text source

### Breakthrough Advertising
High confidence for concepts such as existing desire, awareness, sophistication, intensification, identification, gradualization, redefinition, mechanization, concentration, and camouflage.

### This Is Marketing
High confidence for concepts such as smallest viable market, worldview, status, affiliation/dominance, trust, tension, permission, positioning edges, and funnel thinking.

## Tier B — condensed / secondary source

### The Copywriter's Handbook supplied file
The supplied document is a 25-page summary. It captures useful principles such as reader-first copy, benefit orientation, headline jobs, clarity, 4U-style evaluation, proof, USP, and research questions, but it should not be treated as a complete representation of the full book.

### Hook Point supplied file
The supplied document is a third-party Bookey summary. It is useful for hook creation, packaging, short-attention environments, testing, storytelling, listening, value, and hook fatigue, but the exact wording and emphasis may reflect the summarizer as well as Brendan Kane.

## Operational rule

Use these sources as inputs, not scripture. Current market evidence should override any framework when the two conflict.
